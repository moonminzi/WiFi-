# NAGO TL (iOS)

망가·웹툰 페이지와 실제 사진(간판·메뉴·안내문)의 글자를 **한국어로 바꿔 그 자리에 그려 주는** 번역기.
NAGO VPN·NAGO DL과 따로 설치하는 앱이고, 화면은 같은 터미널 테마(`WifiScan/Theme.swift`, JetBrains Mono)를 쓴다.
아이콘은 초록 말풍선 안의 `가`.

## 왜 이렇게 만들었나 (번역 엔진은 하나)

인터넷 번역기(파파고·구글 렌즈·DeepL)와 AI를 다 놓고 따져 보면, 망가 번역 품질은 **글자를 얼마나 잘 읽느냐**와
**앞뒤 맥락을 아느냐**에서 갈린다. 일본 망가의 세로쓰기·손글씨·효과음은 기기 OCR(Vision)이나 일반 번역기의
OCR이 잘 못 읽고, 말풍선 하나씩 따로 번역하면 누가 누구에게 하는 말인지, 반말/존댓말, 이름 표기가 페이지마다 흔들린다.

그래서 **Claude에 페이지 그림 전체를 통째로 보여 주고** 한 번에 다 하게 했다:

- 글자 덩어리마다 위치(픽셀 상자)·종류(대사/생각/나레이션/효과음/간판…)·원문·번역·각주를 JSON으로(구조화 출력)
- **앞 쪽 줄거리 요약**과 **작품 용어집**(인물 이름·지명·기술 이름)을 매번 같이 줘서 페이지가 바뀌어도 말투·이름이 그대로
- 새로 나온 이름은 Claude가 용어집에 더한다. 작품 설정에서 고치면 다음 번역부터 그 표기를 쓴다
- 사용자가 적는 작품 메모(등장인물 관계·말투)도 같이 준다

**엔진과 비용** (공식 가격표 기준, 1200×1700 쪽 하나 ≈ 그림 2.6천 + 글 1.6천 입력 토큰)

| | 모델 | 한 쪽 | 5달러로 |
| --- | --- | --- | --- |
| 기본 | Claude Haiku 5.5 ($0.10 / $0.50 per MTok) | 약 0.3센트 | 약 1,500쪽 |
| 고급(쪽마다 골라서) | Claude Opus 5.5 ($4 / $20 per MTok) | 약 12센트 | 약 40쪽 |

- 기본은 Haiku 5.5. 잘 못 읽었거나 거절된 쪽만 뷰어 `⋯` → **고급 번역**(Opus 5.5)으로 다시 한다
- Opus는 안전 분류기가 오판하면 서버가 다른 모델로 다시 돌린다(`fallbacks: "default"`). Haiku 5.5에는 이 기능이 없어서 보내지 않는다
- **예산 한도**(기본 5달러): 앱이 쓴 돈을 세어 한도를 넘으면 번역을 멈춘다. 설정에서 바꾼다

번역문을 그림에 다시 넣는 건 기기에서 한다(`Core/`):

1. **말풍선 찾기**: Claude가 준 상자 가운데의 바탕색에서 시작해 바탕색끼리 번져 닫힌 곳(말풍선)을 찾는다.
   상자가 조금 어긋나도, 이어진 말풍선이어도 된다. 그림이 든 흰 칸을 말풍선으로 잘못 잡지 않게 안에 갇힌 게 거의 다
   글자인지 확인한다
2. **원문 지우기**: 말풍선 안에 갇힌 글자 픽셀(후리가나·문장부호 포함)만 지우고 둘레 바탕색으로 채운다. 테두리와
   바깥 그림은 건드리지 않는다. 테두리 없는 글자는 글자 크기 잉크 덩어리만 지운다(옆 그림 선은 남긴다)
3. **한글 앉히기(식자)**: 말풍선 모양(타원이면 가운데 줄이 길게)대로 줄마다 쓸 수 있는 폭을 구해, 들어가는 가장 큰
   크기를 찾는다. 줄은 띄어쓰기에서 나누고(낱말 중간은 글자가 훨씬 커질 때만), 줄 길이를 고르게, 문장부호가 줄 머리에
   오지 않게. 원문 글자 크기를 넘지 않는다
4. **말풍선 없이 그림 위에 쓴 글자**(예: 분홍 글자 + 흰 테두리를 일러스트 위에 바로): Claude가 글자색·테두리색·세로쓰기
   여부도 알려 주고, 기기에서
   - 상자 안과 둘레의 색 분포를 비교해 **글자에만 있는 색**(글자색과 테두리색)만 골라 마스크를 만든다.
     옷 주름·피부·그림 선처럼 둘레에도 있는 색은 건드리지 않는다. 흰 테두리 그물을 말풍선으로 잘못 보지 않게 막았다
   - 지운 자리는 둘레 그림에서 비슷한 조각을 찾아 이어 붙여(PatchMatch, 여러 크기에서) 그림을 되살린다
   - 한글은 **원문과 같은 글자색·테두리**로, 원문이 세로이고 자리가 좁고 길면 **세로쓰기**(열은 오른쪽부터,
     괄호·물결·말줄임표는 돌리고 쉼표·마침표는 칸 오른쪽 위, 따옴표는 낫표로)
   - 한계: 글자가 그림의 중요한 부분(얼굴·손 등)을 넓게 덮고 있으면 그 밑은 원래 그림을 알 수 없어 둘레를 이어 그린
     어림값이다. 대부분 그 위에 한글이 다시 올라가서 눈에 덜 띈다
5. **효과음·추임새**(ニヤニヤ♥, ガタッ 같은 것): 4번과 같은 방법으로 지우고 **원래 색·테두리·세로쓰기 그대로** 한글
   (히죽히죽♥, 덜컥)로 다시 쓴다. 효과음은 더 깐깐하게 본다 — 글자가 둘레와 뚜렷이 다르고, 넓혀 봐도 상자 밖으로
   이어지지 않을 때만. 자신 없으면 **원문 그대로** 두고(판으로 덮지 않는다) 그 자리를 누르면 번역을 볼 수 있다.
   설정에서 "원문 그대로"를 고르면 효과음은 늘 손대지 않는다
   - 글자를 지나가는 같은 색 그림 선(팔 윤곽·효과선)은 상자 안 부분만 지웠다 되살리고, 상자와 닿지 않는 같은 색
     그림(흰 옷깃 등)은 건드리지 않는다
6. **사진 위 글자**: 글자색이 둘레와 구별이 안 되면, 둘레가 매끈한 면(간판·종이)이면 둘레 색을 이어 덮고(구글
   렌즈처럼) 그 위에 쓰고, 그림·사진 결이면 둘레 그림 조각으로 상자를 메운 뒤 테두리 글자로 쓴다(흰·단색 판 없음)

이미 번역한 쪽은 **다시 그리기**(뷰어 `⋯`, 책 화면 더보기 → 모두 다시 그리기)로 Claude를 다시 부르지 않고(무료)
새 그리기 방식·바뀐 설정을 적용할 수 있다.

## 기능

- **서재**: 사진 앱에서 여러 장, 파일 앱에서 그림·**CBZ/ZIP**·**PDF**를 가져오면 한 권(ZIP·PDF는 하나씩 한 권,
  여러 권을 한 ZIP에 묶은 것도 권마다). 다른 앱의 "다음으로 열기"도 된다. 파일은 iOS 문서 선택기가 앱 안으로 복사해
  넘겨 주고(iCloud 파일도 다 받은 뒤), 가져오는 동안 몇 쪽째인지·못 읽은 파일과 이유를 보여 준다
- **전체 번역**: 동시에 3쪽씩. 번역 중에는 화면이 꺼지지 않는다(앱은 켜 두기)
- **뷰어**: 일본 망가는 오른쪽→왼쪽 넘기기, 세로로 긴 웹툰은 세로 스크롤(자동, 작품 설정에서 바꿀 수 있음).
  두 손가락 확대, 두 번 눌러 확대. **보고 있는 쪽과 다음 두 쪽을 먼저 번역**해 둔다. `번역/원문` 단추로 바로 비교
- **말풍선 누르기**: 원문·각주를 보고, 번역을 고치거나 **다른 표현 3개**를 받아 고르거나, 그 말풍선만 원문 그대로 두기.
  고치면 그 쪽만 다시 그린다(다시 번역하지 않음)
- **사진 탭**: 찍거나 앨범에서 한 장 골라 바로 번역
- **내보내기**: 사진 앱에 저장(한 쪽/모두), CBZ로 공유
- **비용 표시**: 쪽·책마다 실제로 답한 모델의 값으로 센 금액, 남은 예산과 남은 쪽 수 어림
- Claude API 키는 **기기 키체인에만** 저장(저장소·IPA에 없음). 설정 탭에서 한 번 넣는다

## 구조

| 경로 | 내용 |
| --- | --- |
| `Core/` | 엔진(SwiftPM `NagoTLCore`, UI 없음). 리눅스/맥에서 `swift test` |
| `Core/.../Refiner.swift` | 말풍선 찾기, 지울 픽셀 고르기, 번역 자리, 이어진 말풍선 나누기, 그림 위 글자 색으로 골라내기 |
| `Core/.../Inpaint.swift` | 지운 자리 채우기(바깥부터 안쪽으로), 사진용 둘레 색 면(쿤스 패치), 그림 되살리기(PatchMatch) |
| `Core/.../Typesetter.swift`, `Placement.swift` | 말풍선 모양대로 한글 줄 나누기·크기 찾기, 세로쓰기, 색·굵기·테두리 |
| `Core/.../Claude.swift` | 엔진(Haiku/Opus)·가격, 서버가 그림을 줄이는 규칙(28px 칸)대로 미리 맞추기, 요청 본문·지시문·JSON 스키마, 스트리밍(SSE) 읽기, 오류, 긴 웹툰 조각 내기·합치기, 용어집 |
| `Core/.../Zip.swift` | ZIP/CBZ 읽기(deflate 풀기 직접 구현)·쓰기 |
| `App/` | SwiftUI 화면, CoreText로 글자 그리기, 번역 대기열 |
| `tools/make_test_pages.py` | 정답 글자 마스크가 있는 가짜 망가 페이지(지우기 시험용) |
| `tools/make_icon.py` | 앱 아이콘 |

## 시험

```sh
swift test --package-path NagoTL/Core
# 가짜 망가 페이지로 지우기·배치까지(원문 픽셀 97% 이상 지워졌나, 테두리·그림이 살아 있나)
python3 NagoTL/tools/make_test_pages.py /tmp/tlfix
NAGOTL_FIXTURES=/tmp/tlfix swift test --package-path NagoTL/Core --filter FixtureTests
```

## 빌드

`.github/workflows/build-tl-ipa.yml`이 `NagoTL/**`가 바뀌면 시험 → xcodegen → 서명 없는 빌드 → ad-hoc 서명 IPA를
`nagotl-N` 프리릴리스로 올린다. 본인 인증서로 재서명해서 설치한다.
