**2.1.0**
- 유저용에도 임시 서버 나라 9곳(sg de fr ie se ca br au in). 나라 카드 아래 `▸ // on demand`(처음엔 접힘)에서 고르면
  서버를 만들어(1분쯤) 붙고, 30분 동안 안 쓰면 서버가 스스로 지워진다. 한꺼번에 2대까지(관리자·친구 합쳐서)
- dash에 임시 서버 나라: 지금 떠 있거나 이번 달에 쓴 나라가 서버 목록·지도·비용에 같이 나온다
  (가동 시간, 이번 달에 만든 서버 수, 시간·송신량·비용). 떠 있는 서버는 눌러서 `delete now`로 바로 지울 수 있다
