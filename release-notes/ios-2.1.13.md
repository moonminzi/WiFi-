NAGO VPN iOS 2.1.13

**2.1.13 — 서버를 AWS에서 Vultr로 옮김**
- **꼭 할 것(한 번)**
  1. 새 `WifiScanVPN.mobileconfig`(저장소 `server/`) 설치 → 설정 → 일반 → 정보 → **인증서 신뢰 설정**에서 **"NAGO VPN Root CA"** 켜기.
     서버 인증서를 새 CA로 바꿨다(예전 "WifiScan VPN Root CA" 프로필은 이걸로 바뀐다)
  2. settings의 비밀번호를 **새 비밀번호**로(예전 비밀번호면 403)
- 국가 API · dash가 서울 Vultr 서버(`141.164.54.197:8443`)로. 늘 있는 서버는 꺼지지 않는다(켜지는 기다림 없음)
- 지역 표시가 Vultr 코드(icn · nrt · sea · lhr …), 미국은 시애틀, 캐나다(임시)는 토론토
- 임시 서버 나라: 만들기 1~2분, 30분 안 쓰면 지워진다. **아일랜드는 빠짐**(Vultr에 지역이 없음)
