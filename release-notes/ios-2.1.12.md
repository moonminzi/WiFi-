**2.1.12**
- **Safari 메뉴 "NAGO"(웹 확장)** — Safari 주소창의 aA(또는 퍼즐) → NAGO:
  - NAGO Blocker(배너 차단기)가 켜졌는지 · 규칙 수
  - **hide an element** — 누르고 페이지의 배너를 탭 → 빨간 테두리 → `hide`. 그 사이트에서 계속 숨긴다(`↑ bigger`는 감싼 칸까지)
  - 이 사이트에서 내가 숨긴 것 목록(× 로 되돌리기) · **pause on this site**
  - 켜기: iOS 설정 → 앱 → Safari → 확장 프로그램 → **NAGO** 켜고 "모든 웹 사이트" 허용
- **차단기 켜짐 확인 고침** — 재서명하면 번들 ID가 바뀌어 앱이 차단기를 못 찾던 것. 이제 앱 안의 확장을 직접 찾는다.
  settings → `// safari`에 이유가 보이고 `test in safari`(차단 시험 페이지) · `recheck` 버튼
- 재서명하면 확장이 넷(앱 · 터널 · 차단기 · NAGO)
